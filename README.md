## Overview

This project focuses on predicting house prices using Machine Learning techniques. The goal is to build a regression model that can estimate property prices based on various features such as area, number of rooms, and other attributes.

The implementation is performed using Python in Google Colab.

---

## Objective

* Perform data preprocessing
* Select relevant features
* Train regression models
* Evaluate model performance using RMSE

---

## Dataset

**House Price Prediction Dataset**

The dataset includes features such as:

* Area (square feet)
* Number of bedrooms
* Number of bathrooms
* Location
* Other property-related attributes

**Target Variable:** Price

---

## Tasks Performed

### 1. Data Preprocessing

* Removed missing values
* Converted categorical features into numerical format using one-hot encoding

---

### 2. Feature Selection

* Selected input features (X)
* Defined target variable (y: price)

---

### 3. Train-Test Split

* Split dataset into:

  * 80% Training data
  * 20% Testing data

---

### 4. Model Training

Trained the following models:

* Linear Regression
* Random Forest Regressor

---

### 5. Model Evaluation

* Evaluated models using **Root Mean Squared Error (RMSE)**
* Compared performance of both models

---

## Results
