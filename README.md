# Task 8: House Price Prediction

## Problem Statement
Build a machine learning model to predict house prices.

## Dataset Details
Dataset includes:
- Area
- Bedrooms
- Age
- Price

## Approach
1. Data preprocessing in Google Colab
2. Model training using Linear Regression
3. Model saved using pickle
4. Streamlit app created for prediction

## Results
The model successfully predicts house prices based on user input features.
